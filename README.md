# Vellor store (static showpiece)
Plain HTML/CSS/JS, no build, no backend. Open index.html or host on GitHub Pages.
- config.js: WhatsApp number, InstaPay address, shipping fee, demo flag (set demo:false when real).
- products.js: PLACEHOLDER products and prices. art.js: placeholder SVG art, replace with real leather photos.
- Orders are prebuilt WhatsApp messages. No payment happens on the site. Cart is saved in the browser only.
