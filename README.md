# Vellor store (static luxury showpiece)
Plain HTML/CSS/JS, no build, no backend. Open index.html or host on GitHub Pages.
- config.js: WhatsApp number, InstaPay address, shipping, demo flag (set demo:false when real).
- products.js: PLACEHOLDER products and prices. img/: AI-generated product and leather images (placeholders: replace with real photos of the factory's products).
- media/film.mp4: slideshow film built from the same images.
- Orders become a prefilled WhatsApp message. No payment happens on the site. Cart is saved in the browser only.
